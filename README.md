# Play Feel Express — Guitar Academy Website

A responsive, single-page website for your online guitar classes.

## Included
- `index.html` — website content and sections
- `style.css` — responsive dark/charcoal + yellow styling
- `script.js` — mobile navigation and current footer year
- `assets/guitar-class-poster.jpeg` — your supplied poster

## Run on Windows
1. Extract `guitar_academy_website.zip`.
2. Open the extracted folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.
4. To publish free, upload the folder to GitHub and enable GitHub Pages, or deploy it on Netlify.

## Before publishing
- Confirm the Instagram handle in `index.html` is `__rajuplugged`.
- Add your class prices, exact schedule, location (if relevant), and testimonials when ready.
- Google Fonts need an internet connection; the site still uses fallback fonts if offline.
